# Architecture decision records

An ADR records **one** decision: the context, the options, the choice and its
consequences. It fits on one page.

- **An ADR is never rewritten.** A later decision that changes it gets a new ADR
  that supersedes it, and the old one's status says so.
- **Number them in order:** `0001-target-architecture.md`,
  `0002-...`.
- **Start from** [`0000-template.md`](0000-template.md).
- **Every group member writes at least one ADR** during the course.

The format follows Michael Nygard's "Documenting Architecture Decisions" (2011),
with two sections added for this course: the options considered and the
criteria.
